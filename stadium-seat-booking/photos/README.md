# Venue photographs

Drop a photograph of a venue here, named after its venue id, and it replaces the drawn
seating plan on that venue's details page. Restart the application to see it.

Accepted formats: `.jpg`, `.jpeg`, `.png`.

No photographs are committed to this repository. Pictures of these venues are third-party
work with their own rights, and the public repository is not the place for them. The drawn
plan that appears instead is generated from each venue's real shape, sections and colours, so
it is accurate as it stands.

The image files are ignored by git on purpose so they cannot be committed by accident.
Remove the ignore lines in `.gitignore` if you hold the rights and want to publish yours.
